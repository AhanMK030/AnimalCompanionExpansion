# Animal Companion Expansion / 动物伙伴扩展

A companion expansion mod for Pathfinder: Wrath of the Righteous, with custom animal companions, models, animations, abilities and Chinese/English localization.

本仓库用于分发动物伙伴扩展的 Release 安装包。

Download the complete installation archive from [Releases](https://github.com/AhanMK030/AnimalCompanionExpansion/releases). Requires [TabletopTweaks-Core](https://github.com/Vek17/TabletopTweaks-Core); install with Unity Mod Manager while the game is closed.

请在游戏关闭时通过 Unity Mod Manager 安装完整发行包，并安装前置 TabletopTweaks-Core。
